# CS-210 Corner Grocer Item Tracker

This project involved creating a grocery item tracking program that reads purchase data from a text file and allows users to view item frequencies through a menu-driven interface. The program solves the problem of manually counting how often items appear in a daily purchase record by automatically processing the data and presenting the results in both numerical and histogram formats. The project required file handling, data storage, user input validation, and object-oriented programming concepts to create a complete and functional application.

One aspect of this project that I am most proud of was the organization of separating the program into multiple classes with clearly defined responsibilities. Separating the menu system, item tracking functionality, and file management logic into their own files improved readability and made the code easier to maintain. This modular approach also reduced duplication and made troubleshooting simpler when issues arose. Although the program meets the project requirements, there are several areas where it could be enhanced. Additional input validation could further protect against invalid user entries, and more robust error handling could be implemented for missing or corrupted data files. These improvements would increase the program's reliability and overall user experience.

The most challenging part of the project was implementing the file processing logic and ensuring that item names were counted correctly, regardless of how often they appeared in the input file. Managing data between files and classes while maintaining proper program flow required careful planning and testing. To overcome these challenges, I relied on course materials, instructor resources, documentation, and debugging techniques to identify and correct issues. Through this process, I strengthened my understanding of file input/output operations, data structures, object-oriented design, and program organization.

The skills developed during this project will be highly transferable to future coursework and software development projects. Working with classes, header files, source files, file streams, and modular program design are foundational skills that will continue to be used throughout my computer science degree and professional career. I made the program maintainable, readable, and adaptable by using meaningful function names, separating responsibilities into dedicated classes, and following a consistent coding structure. This design allows future modifications to be implemented more easily while keeping the code organized and understandable for both other developers and me.
